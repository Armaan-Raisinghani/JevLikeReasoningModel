# Jev efficiency experiments

Focused working repository for the current Qwen fast/reasoning cascade experiments.

- `train_jev_efficiency_experiments.py`: experiment pipeline and model variants.
- `run_jev_smoke.sh`, `run_jev_full.sh`: Slurm launchers.
- `efficiency_variant_comparison.md`: smoke-test comparison and current interpretation.
- `jev_efficiency_results/14662/`, `jev_efficiency_results/14979/`: run analyses and configurations.

Model weights, datasets, caches, checkpoints, and raw prediction archives are not included.
